# Privacy Settings

**Privacy settings** are available from the footer on the MapStore home page, map viewers, Dashboards, GeoStories and embedded resources. On routes without a native footer, MapStore provides a bottom bar with the same entry point.

## First visit

The common panel opens on the first visit, including when a resource is opened directly. It links to the installation's Cookie Policy, Privacy Policy and Terms of Use.

The standard Vanilla configuration uses necessary tools only. The panel provides information and a **Close** action. Closing this information does not express consent or accept the Terms of Use. MapStore remembers the dismissal separately from optional consent choices.

Categories that the installation does not use display **Not used** and have no switches. The necessary category remains active for the requested service.

## Optional tools

If the operator configures optional integrations, the panel provides **Reject optional**, **Accept optional** and **Customize** actions. Optional categories are off before a choice.

Use **Customize** to select categories, then **Save choices**. Closing an initial optional-choice panel keeps optional tools off and records that refusal. You can continue using MapStore after refusing optional tools.

## Change or withdraw a choice

Reopen **Privacy settings** from the footer to change a selection or withdraw all optional consent. Changes are shared with other tabs on the same application origin. Expired choices and choices for an older policy version do not enable optional tools.

Withdrawal stops registered integrations and cancels supported active requests. It cannot retract data already transmitted or delete cookies belonging to another domain. Contact the installation operator for requests concerning account or server-side data.

The policy templates are a starting point for the installation operator. Their content and the available categories depend on the actual services configured for the installation.
