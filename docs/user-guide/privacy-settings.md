# Privacy Settings

**Privacy settings** are available from the footer of the MapStore home page and, in Maps, Dashboards, GeoStories and the context creator, as the last entry of the user menu. Embedded maps show an icon (a shield with a user) next to the map credits, other embedded resources the same icon as a small button in the bottom left corner. The login window shows a **Privacy settings** button at its bottom.

## First visit

The common panel opens on the first visit, including when a resource is opened directly. It links to the installation's Cookie Policy, Privacy Policy and Terms of Use. Until the installation configures its own pages, the links open the MapStore template pages, and the panel shows a warning that they are templates.

The standard Vanilla configuration uses necessary tools only. The panel provides information and a close button (X) in the top right corner. Closing this information does not express consent or accept the Terms of Use. MapStore remembers the dismissal separately from optional consent choices.

Categories that the installation does not use display **Not used** and have no switches. The necessary category remains active for the requested service.

## Optional tools

If the operator configures optional integrations, the panel shows a switch for each optional category, and the **Reject all** and **Accept all** actions. Optional categories are off before a choice.

Each switch saves the choice for its category at once. Closing an initial optional-choice panel keeps optional tools off and records that refusal. You can continue using MapStore after refusing optional tools.

## Change or withdraw a choice

Reopen **Privacy settings** to change a selection, or use **Reject all** to withdraw all optional consent. Changes are shared with other tabs on the same application origin. Expired choices and choices for an older policy version do not enable optional tools.

Withdrawal stops registered integrations and cancels supported active requests. It cannot retract data already transmitted or delete cookies belonging to another domain. Contact the installation operator for requests concerning account or server-side data.

The policy templates are a starting point for the installation operator. Their content and the available categories depend on the actual services configured for the installation.
